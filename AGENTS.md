# Правила для AI-агентов

Сначала прочитай `SERVICE.md`, README и ADR-0015 в репозитории `platform`. Не меняй границы сервиса
без нового ADR. Пиши тест до поведения. Используй простые английские имена и четыре пробела. Не
храни секреты, настоящие токены, пользовательские данные и адреса окружений.

Используй обычные слои Spring MVC: controller вызывает service, service содержит правила, repository
работает с jOOQ. Не используй JPA. Контроллер не обращается к repository напрямую. Обновляй
`SERVICE.md`, контракт и runbook в том же pull request.
